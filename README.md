# Falculator


## О проекте

Рассчетный модуль для производственных цепочек на и химических рецептов Factorio,
чтобы по графу зависимостей можно было автоматически высчитывать нужные ресурсы,
промежуточные компоненты и объемы потоков под конечный предмет

## Технологии

- Python
- PostgreSQL
- Docker
- Docker Compose
